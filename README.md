# 🚀 Kite AI Prototype Boilerplate

Бойлерплейт для быстрого прототипирования интерфейсов с помощью AI и Kite Design System.

> **Для кого:** Product Owners, дизайнеры, и все, кто хочет быстро создавать прототипы без глубоких знаний программирования.

---

## 📋 Что это?

Этот репозиторий — готовая основа для создания прототипов с использованием:
- **Kite Design System** — библиотека UI-компонентов Туту
- **AI-ассистент** (Cursor IDE) — генерирует код по вашему описанию
- **Next.js + React** — современный стек для веб-приложений

AI автоматически использует компоненты Kite благодаря загруженным директивам — вам достаточно описать что вы хотите увидеть.

## 🛠️ Предварительные требования

Перед началом работы убедитесь, что у вас установлены следующие инструменты.

### Как открыть Терминал (macOS)

**Терминал** — это приложение для ввода текстовых команд. Чтобы его открыть:

1. Нажмите **Cmd + Пробел** (откроется Spotlight — строка поиска)
2. Введите **Terminal** или **Терминал**
3. Нажмите **Enter**

Откроется окно с текстовым интерфейсом. Сюда вы будете вставлять команды.

> **Совет:** Чтобы вставить скопированную команду в Терминал, используйте **Cmd + V**

**🤖 Через AI-агента** — скопируйте в чат Claude Code, Cursor или другого AI-агента с доступом к терминалу:

**📋 Самостоятельная настройка**

### 1. Git

В Терминале выполните:

```bash
git --version
```

Если Git не установлен, вы увидите предложение установить его или ошибку. Для установки:

**Установка через Homebrew (рекомендуется для macOS):**

1. Сначала установите Homebrew. Скопируйте эту команду и вставьте в Терминал (Cmd+V):
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

2. После установки Homebrew, установите Git:
   ```bash
   brew install git
   ```

### 2. Node.js

Проверьте наличие:
```bash
node --version
```

Если не установлен, скачайте **LTS версию**: https://nodejs.org/en/download/

Или через Homebrew:
```bash
brew install node@20
```

### 3. Cursor IDE (или альтернатива)

Скачайте и установите: https://cursor.sh/download

Cursor — это AI-редактор на базе VS Code, который позволяет генерировать код по текстовому описанию.

> **Альтернативы:** Директивы нативно поддерживают **Claude Code** (деплой: `kite-ai-deploy --env claude --yes .`). Также можно использовать другие AI-инструменты (ChatGPT, GitHub Copilot и др.) с профилем `--env generic` — загрузите `START.md` в контекст AI.

### 4. SSH-ключ (необязательно)

SSH-ключ позволяет безопасно подключаться к репозиториям без ввода логина и пароля каждый раз. Это удобнее, чем HTTPS — после настройки вам не нужно вводить учётные данные.

**Создание SSH-ключа:**

1. Откройте Терминал и выполните:
   ```bash
   ssh-keygen -t rsa -b 4096 -C "ваш.email@tutu.ru"
   ```

2. Нажимайте **Enter** на все вопросы (можно оставить пустой пароль для удобства)

3. Скопируйте публичную часть ключа:
   ```bash
   cat ~/.ssh/id_rsa.pub | pbcopy
   ```
   Ключ скопирован в буфер обмена.

4. Добавьте ключ в Bitbucket:
   - Откройте: https://stash.tutu.ru/plugins/servlet/ssh/account/keys
   - Нажмите **Add key**
   - Вставьте ключ (Cmd+V) и сохраните

После этого вы сможете клонировать репозитории по SSH без ввода пароля.

> **Не хотите настраивать SSH?** Это необязательно — при клонировании можно использовать HTTPS с логином и паролем от Bitbucket.

## 📚 Полезные команды
